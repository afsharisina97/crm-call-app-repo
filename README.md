# CRM تماس (پوسته‌ی fastAPK + پل `AndroidCRM`)

این ریپو یک fork از fastAPK است. وب‌اپ CRM روی دامنه می‌ماند و اپ فقط کارهایی را که مرورگر نمی‌تواند (لاگ تماس، پیامک، ضبط) از طریق پل `window.AndroidCRM` در اختیار صفحه می‌گذارد. نصب فقط به‌صورت APK مستقیم است، نه از Play.

## وضعیت (مرحله‌ی ۱: تست اتصال)
- پل `AndroidCRM`: `ping()` `status()` `askPermissions()` `openAccessibility()` `openAppInfo()` `lastCalls(n)` — همه JSON برمی‌گردانند و فقط وقتی صفحه `<meta name="fastapk-features" content="crm">` داشته باشد کار می‌کنند.
- `CrmAccessibilityService`: فعلاً خالی است و فقط فعال‌شدنش قابل‌چک است. ضبط تماس بعد از تست روی گوشی واقعی اضافه می‌شود.
- مجوزها: لاگ تماس، وضعیت تلفن، خواندن/ارسال پیامک، میکروفون.
- این کد روی گوشی کامپایل و تست نشده؛ اولین بیلد را از GitHub Actions بگیرید و اگر خطا داد، متن خطا را بفرستید.

## مراحل بعدی
۲. ارسال لاگ تماس به API دامنه  ۳. آزمایش ضبط (Foreground Service + سرویس دسترسی‌پذیری)  ۴. پیامک ورودی/خروجی  ۵. نمایش اطلاعات مشتری هنگام زنگ‌خوردن.

## نصب روی گوشی
۱. APK را از Actions بگیرید و نصب کنید (لینک سایت = آدرس پوشه‌ی صفحه‌ی تست، با `/` آخر).
۲. صفحه‌ی تست را باز کنید: «درخواست مجوزها» را بزنید.
۳. اندروید ۱۳+: «تنظیمات اپ» ← منوی ⋮ ← Allow restricted settings.
۴. «تنظیمات دسترسی‌پذیری» ← اپ را روشن کنید. بعد «بررسی دوباره».

# اپ من

اپ اندروید وب‌ویو برای آدرس: `https://example.com`
پکیج: `com.example.myapp`

برای تغییر آدرس سایت، اسم اپ یا پکیج:
- آدرس سایت: `app/src/main/java/com/example/myapp/MainActivity.java` → `SITE_URL`
- اسم اپ: `app/src/main/res/values/strings.xml` → `app_name`
- پکیج: تو `app/build.gradle` (`namespace`, `applicationId`) و مسیر پوشه‌ی جاوا

## استفاده‌ی سریع (دراپ‌دون خودِ گیت‌هاب)
۱. این پروژه رو پوش کن (بدون نیاز به آیکون).
۲. تو ریپو برو تب **Actions** → روی ورک‌فلوی **Build APK** کلیک کن → دکمه‌ی سبز **Run workflow** با اون فلش/مثلث کنارش رو بزن.
۳. تو همون پنل بازشده: **لینک سایت**، **اسم اپ** (فارسی هم می‌شه)، **لینک مستقیمِ تصویر آیکون** (یه جا آپلودش کن — مثلاً imgur یا هر هاست دیگه — و لینک مستقیم فایل رو اینجا بده)، **زوم صفحه** (پیش‌فرض ۹۹؛ یا تیکِ «زوم پیش‌فرض» رو بزن تا دست‌نخورده بمونه)، تیکِ **تمام‌صفحه**، (اگه تمام‌صفحه رو خاموش کنی) دو تا فیلد **رنگ نوار بالا/پایین**، و تیکِ **ساخت Release** رو پر کن و **Run workflow** رو بزن.
نکته (چند اپ روی یه گوشی): هر لینک خودکار یه Package ID مخصوص خودش می‌گیره (مثل `com.webapp.shop_example_ir_7e8972`)، پس اپ‌هایی که برای لینک‌های مختلف می‌سازی رو می‌شه کنار هم نصب کرد و «قبلاً نصب شده» نمی‌ده. اگه خودت خواستی، فیلد **Package ID** رو پر کن.

۴. چند دقیقه صبر کن، رو اجرای سبزرنگ کلیک کن، پایین صفحه از بخش **Artifacts** فایل apk رو دانلود کن.

نکته درباره‌ی لینک آیکون: باید لینک مستقیم خودِ فایل تصویر باشه (چیزی که وقتی تو مرورگر بازش می‌کنی، خودِ عکس رو نشون بده نه یه صفحه‌ی وب) — مثلاً آدرسی که به `.png` یا `.jpg` ختم می‌شه. اگه خالی بذاریش، آیکون فعلی پروژه دست‌نخورده می‌مونه.

اگه هیچ‌وقت این ورک‌فلو رو دستی اجرا نکنی و فقط پوش کنی، با مقادیر پیش‌فرض (example.com، آیکون فعلی، تمام‌صفحه روشن، فقط Debug) می‌سازه.

## Release امضاشده
۴ مقدار `KEYSTORE_BASE64` / `KEYSTORE_PASSWORD` / `KEY_ALIAS` / `KEY_PASSWORD` رو در Settings → Secrets and variables → Actions ست کن، بعد موقع Run workflow تیکِ Release رو هم بزن.

## چاپ (فیش صندوق)
`window.print()` توی وب‌ویو به‌صورت پیش‌فرض کار نمی‌کنه. این نسخه یه پل `AndroidPrint` داره که چاپ رو به سرویس چاپ خود اندروید می‌فرسته (اندازه‌ی ۸۰/۵۸ میلی‌متر، A5 و A4 از انتخابگر خود اپ).
برای پرینتر حرارتی بلوتوثی، تو گوشی یه افزونه‌ی چاپ نصب کن (مثل RawBT Print Service) و پرینتر رو توش جفت کن؛ بعد تو پنجره‌ی چاپ اندروید همون پرینتر رو انتخاب کن.
